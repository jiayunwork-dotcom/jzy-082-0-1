车辆动力学组在做整车纵向牵引与制动仿真时，需要一个稳定的轮胎纵向力计算后端，把经验轮胎模型固化成可被仿真主循环高频调用的 HTTP 服务，避免每个仿真项目各自重写一遍公式又算得不一致。

服务实现经典的经验轮胎纵向力模型。调用方给出轮胎垂直载荷、纵向滑移率，以及一组形状系数（分别控制曲线的刚度、形状、峰值幅度与曲率），或者给出摩擦系数与其余形状系数、由载荷推出峰值幅度；服务返回该工况下的纵向力，以及在给定系数下这条力—滑移曲线的峰值滑移率与峰值力。核心表达式把滑移率经过刚度、曲率修正后送入反正切，再经形状系数与峰值幅度映射为纵向力；峰值幅度既可直接给定，也可由摩擦系数与垂直载荷相乘得到，但这条「摩擦系数乘载荷等于峰值幅度」的换算只能在一个地方定义，供单点计算与曲线扫描共用，不允许两处各算一份导致对不上。

除了单点计算，还要能对一段滑移率区间做扫描，在这条曲线上找到纵向力绝对值最大的点，作为峰值滑移率与峰值力返回。扫描与单点计算必须共用同一套系数与同一个公式：在扫描得到的峰值滑移率处，用单点公式重新求值应当与扫描报告的峰值力一致。若某次扫描因故中途未完成，绝不能把不完整的结果当成一条成功的曲线返回。

有几条物理上必然成立的关系请作为正确性基准并用测试锁死：滑移率为零时纵向力为零；仅把滑移率取相反数，纵向力大小不变、方向相反（模型不含额外的水平偏移）；在峰值幅度与垂直载荷成正比的设定下，仅把载荷成倍放大，峰值力同比例放大；在标准形状下，任一工况的纵向力绝对值不超过峰值幅度（允许合理数值容差）。输入校验要在计算前完成：垂直载荷非正视为载荷非法，形状系数取到使曲线不存在有意义峰值的退化取值（例如形状因子非正或刚度为零）视为形状非法，都返回结构化错误；滑移率绝对值超出常规范围时可给出告警但仍照常计算。

对外用 JSON 交互，至少提供：一个由载荷、滑移率与系数返回纵向力与所用峰值幅度的入口；一个由系数与载荷返回峰值滑移率与峰值力的入口；一个接收滑移率网格、返回整条曲线采样点列的入口。服务要能并发承接多路仿真请求，各请求的系数与扫描中间量彼此隔离、互不覆盖。为便于核对，内置一份乘用车量级的示范参数，加载后在小滑移率下纵向力方向与滑移率一致且大小低于峰值幅度，便于快速自检。

开发语言定为 Go 1.22，HTTP 层用 Gin 框架搭建。请把工程按内核职责分包：滑移率与曲率修正、主曲线公式求值、峰值幅度与垂直载荷的换算、滑移区间的扫描寻峰、参数合法性校验、以及接口层，各自成包成文件，切忌把公式求值和扫描寻峰揉进一个巨型文件。测试要能证明这些性质：零滑移得零力、滑移变号则力反向而幅值不变、载荷成倍放大时峰值力等比放大、任意工况纵向力不越过峰值幅度、以及扫描出的峰值点用单点公式复算能对上。以容器镜像形式交付，一条命令即可构建并启动、监听端口对外服务，运行时基础镜像取 Go 1.22。这个服务专注于轮胎纵向力这一项计算，只经 HTTP 提供能力，不做任何网页，也不牵涉转向几何、悬架系统或车辆档案。
